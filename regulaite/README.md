### 📥 Bring-your-own law

1. Drag a PDF onto the "Add Regulation" pane.  
2. UI shows token + cost estimate.  
3. Click **Embed** → only key sections (Art 5 / Annex III etc.) are chunked & embedded, cutting costs by ~80 %.  
4. Re-scan to see new jurisdiction risk labels live.

Key features:
- Smart extraction of relevant sections reduces token usage by ~80%
- Client-side token estimation before upload
- Automatic jurisdiction detection from filename
- Real-time cost calculation
- Seamless integration with existing risk assessment
